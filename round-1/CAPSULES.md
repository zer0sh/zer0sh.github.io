# Round 1: Concept Capsules (A–J)

### Direction A — Capsule
- **Premise:** Raw unadorned Unix kernel run-book / telemetry dispatch. Single-beam CRT phosphor terminal.
- **Font Stack:** Monospace (`ui-monospace, 'Cascadia Code', 'Source Code Pro', Menlo, Monaco, Consolas, monospace`).
- **Color System (1-Color):** Canvas `#09090b`. Active text `#ff9e3b` (100%).
- **Hierarchy & Scale:** Size scale 10px (eyebrow) to 72px (h1). Tracking: +0.28em on metadata, -0.04em on display headers.
- **Signature Relationship:** Monospaced tabular alignment where rigid column offsets define hierarchy without a single line or border.
- **Invariants:** Pure monochromatic text, strict tabular grid, zero decorative non-type elements.

### Direction B — Capsule
- **Premise:** SRE Doctrine Manifesto. Classical high-dignity typography meeting modern distributed systems theory.
- **Font Stack:** High-contrast serif (`Georgia, 'Times New Roman', serif`) + Grotesque sans (`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`).
- **Color System (2-Color):** Canvas `#f6f5f0`. Primary text `#161614` (75%), Secondary text `#72706a` (25%).
- **Hierarchy & Scale:** Size scale 11.5px (metadata) to 88px (h1). Italicized secondary roles (`/ Systems`).
- **Signature Relationship:** Asymmetrical generous left-gutter indentation with monumental serif drop-quote doctrine.
- **Invariants:** Editorial proportion, literary serif dominance, warm plaster ground.

### Direction C — Capsule
- **Premise:** Industrial Blueprint & Observability Telemetry. Distributed systems console specification.
- **Font Stack:** Condensed system sans (`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Arial, sans-serif`) + tabular monospace.
- **Color System (3-Color):** Canvas `#0b1220`. Primary `#f8fafc` (60%), Secondary `#94a3b8` (30%), Accent Cadmium Orange `#f97316` (10%).
- **Hierarchy & Scale:** 3-column asymmetric engineering layout: Spec ID, title, and body technical breakdown.
- **Signature Relationship:** Metric identifier hanging beside architectural role and technology stack specification.
- **Invariants:** 3-column technical layout, blueprint navy ground, orange telemetry accents.

### Direction D — Capsule
- **Premise:** Brutalist Scale Shock. High-impact operational incident response center.
- **Font Stack:** Heavy display sans (`-apple-system, BlinkMacSystemFont, 'Arial Black', sans-serif`) + Monospace data.
- **Color System (4-Color):** Canvas `#08080a`. Primary `#ffffff` (45%), Secondary Acid Lime `#9eff00` (25%), Tertiary Ash `#7f8490` (20%), Accent Hazard Amber `#ffb800` (10%).
- **Hierarchy & Scale:** Extreme scale contrast: giant 150px display headers with 0.85 leading alongside compact micro-spec data.
- **Signature Relationship:** Gigantic numbered indices (`01`, `02`) colliding against heavy condensed uppercase project names.
- **Invariants:** Radical scale shifts, acid lime titles, ultra-condensed uppercase titles.

### Direction E — Capsule
- **Premise:** Swiss International / Mathematical Pure Sans. Neutral, objective, and surgical systems engineering.
- **Font Stack:** Pure neutral grotesque sans (`-apple-system, BlinkMacSystemFont, 'Helvetica Neue', Helvetica, Arial, sans-serif`).
- **Color System (2-Color):** Canvas `#ffffff`. Primary `#0a0a0a` (70%), Secondary `#666666` (30%).
- **Hierarchy & Scale:** Mathematical 50/50 two-column split. Flush-left rag-right composition with deep negative whitespace.
- **Signature Relationship:** Generous horizontal air separating project identifiers from their operational bodies.
- **Invariants:** Stark black and white contrast, absolute lack of ornament, strict baseline rhythm.

### Direction F — Capsule
- **Premise:** Unix Manual Monograph (Bell Labs reference standard). Timeless systems documentation architecture.
- **Font Stack:** Classical transitional serif (`Garamond, 'EB Garamond', Georgia, serif`) for reading text + Monospace (`ui-monospace, Menlo, monospace`) for manual section headers.
- **Color System (3-Color):** Canvas `#f5f0e6`. Primary Iron `#1f1d1a` (70%), Secondary `#78716c` (22%), Accent Vermilion `#b91c1c` (8%).
- **Hierarchy & Scale:** Deep hierarchical outdents: section titles hang out to the left while body text indents strictly by 2.5rem.
- **Signature Relationship:** Bell Labs `MAN(1)` outdents with section codes (`NAME`, `SYNOPSIS`, `OPERATIONAL SYSTEMS`, `SEE ALSO`).
- **Invariants:** Hanging outdent structure, unbleached cream paper, Garamond/Monospace pairing.

### Direction G — Capsule
- **Premise:** Two-Speed Telemetry Stream. Horizontal split: static operational anchor on the left, high-velocity stream on the right.
- **Font Stack:** Technical sans (`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`) + Monospace.
- **Color System (4-Color):** Canvas `#0d1117`. Primary `#f1f5f9` (55%), Secondary Glacial Cyan `#38bdf8` (25%), Tertiary `#64748b` (15%), Accent Solar Amber `#fbbf24` (5%).
- **Hierarchy & Scale:** Split viewport: sticky anchor column (identity, doctrine, links) + continuous reading stream.
- **Signature Relationship:** Sticky operator manifesto anchoring a rapid sequential audit of systems and field dispatches.
- **Invariants:** Split screen structure, sticky left sidebar, cyan/amber telemetry roles.

### Direction H — Capsule
- **Premise:** Architectural Monumental. Solitary, centered, high-gravity gravitas for an infrastructure architect.
- **Font Stack:** Palatino / Book Antiqua serif (`Palatino, 'Palatino Linotype', 'Book Antiqua', Georgia, serif`) + Clean sans metadata.
- **Color System (2-Color):** Canvas Deep Olive `#141713`. Primary Ivory `#fbf8f1` (70%), Secondary Lichen Olive `#8f9686` (30%).
- **Hierarchy & Scale:** Centered vertical monumentality. 44ch measure, generous line height (1.7), deliberate cadence.
- **Signature Relationship:** Deep centered vertical breathing room with measured italic doctrine and small-caps metadata.
- **Invariants:** Centered alignment, deep olive ground, Palatino elegance.

### Direction I — Capsule
- **Premise:** Utilitarian Specimen Catalogue. Physical parts manual and engineering inventory index.
- **Font Stack:** Utilitarian sans (`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`) + Monospace numerals.
- **Color System (3-Color):** Canvas `#ebe8e1`. Primary Ink `#171717` (65%), Secondary Umber `#716c65` (25%), Accent Cobalt `#1d4ed8` (10%).
- **Hierarchy & Scale:** 4-column horizontal tabular index: Number, Name, Narrative Description, Tech Stack.
- **Signature Relationship:** Cobalt sequential numerals hanging down the left margin indexing the operational parts of the engineer.
- **Invariants:** 4-column index structure, stone ground, vivid cobalt numbers.

### Direction J — Capsule
- **Premise:** Whispered Monolith Dispatch. Radical atmospheric scale contrast between faint ambient typography and razor-sharp data.
- **Font Stack:** System sans (`-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`) + Monospace.
- **Color System (4-Color):** Canvas `#090a0d`. Primary Platinum `#f8fafc` (50%), Secondary Acid Emerald `#10b981` (25%), Tertiary Slate `#64748b` (20%), Accent Vermilion `#ef4444` (5%).
- **Hierarchy & Scale:** Extreme scale contrast: giant low-contrast ambient background kicker (`INFRASTRUCTURE`) overlaid with sharp, crisp data points.
- **Signature Relationship:** Ghost background scale contrast framing an ultra-precise high-availability systems stream.
- **Invariants:** Faint background type, acid emerald active indicators, coal black canvas.
